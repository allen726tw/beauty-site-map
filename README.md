# 美業選址小幫手

點地圖任一位置，算出步行圈內的美業開店指數（穿戴甲結合傳統美甲的複合店）。

指數＝人流 40%＋客群 30%＋美業熱度 30%

- 人流：捷運進出人次、來客熱度、步行圈內的百貨商場
- 客群：20–44 歲女性人口、消費熱度、所在行政區白天活動人口
- 美業熱度：美甲、美容、美髮店數，越多分數越高（當加分，不當競爭）

評估對象是街邊門市，不是百貨櫃位。分數還沒算進租金。

資料來源：內政部戶籍人口（115/10）與村里界、內政部電信信令日間活動人口（109/11，鄉鎮市區）、財政部電子發票消費熱度與稅籍登記、臺北捷運進出量、OpenStreetMap 店點；底圖：內政部國土測繪中心臺灣通用電子地圖。
